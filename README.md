# KharchaPaani Lite 💸

A **single-file** smart expense tracker for college students — runs entirely in the browser with no backend needed.

## Features
- **UPI SMS Import** — Paste bank SMS, auto-extract transactions
- **Auto-Categorization** — 80+ Indian merchant keywords
- **Live Sync Demo** — Simulates real-time SMS reading
- **Dashboard** — Health score, trends, donut chart, forecasting
- **100% Client-Side** — No server, no database, data stays on your device

## Tech Stack
- HTML + CSS + JavaScript (single file)
- localStorage for data persistence
- Canvas 2D API for charts
- SHA-256 (Web Crypto API) for password hashing

## Usage
Just open `index.html` in any browser. No setup needed.
